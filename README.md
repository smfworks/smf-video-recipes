# SMF Video Recipes

Recipes a person or an agent can follow to make a video the same way twice.

Each recipe names the machine, the graph, the numbers that were measured, and the failure that taught the rule. A prompt is not a recipe. A successful file is not a finished cast.

## Recipes

- [MiniMax H3 on DGX Spark with ComfyUI](recipes/minimax-h3-comfy-dgx-spark.md) — local 15-second clips, Wasserman 80s horror LoRA, one still per character, latent chain for longer work.

## Rules for adding a recipe

1. Write the host, the service, the port, and how an agent reaches it.
2. Pin numbers you measured. Label anything untested as untested.
3. Include the exact node names and the API key shape that failed.
4. Say what the recipe does not do.
5. Do not put API keys, bearer tokens, or private life in the file.
